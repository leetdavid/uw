---
title: Add an AI provider
description: Connect uw to the models you already use, such as OpenAI, Anthropic, or a local Ollama. Automatic organization and chats need one.
---

## Add *a provider*

1. Open `uw://ai/providers`.
2. Click **Add provider** and pick OpenAI, Anthropic, OpenRouter, Vercel AI Gateway, Ollama, Jev, or Custom.
3. Paste the provider's key. uw lists the provider's models before it adds it.

The key goes to the macOS Keychain. Every profile shares your providers, so you add each one once. For a provider that isn't in the list, use OpenRouter, Vercel AI Gateway, or **Custom**.

Click a provider to see its address, key, format, and models, or to remove it. Each model shows whether it calls tools, which effort levels it takes, and whether it makes decisions.

## Pick *your models*

Under **What uw uses models for**, each row is named for its job:

| Row | What its model does |
| --- | --- |
| **Makes quick choices** | Places tabs, and checks the agent's commands and memories before it runs or keeps them. |
| **Names tasks** | Writes a short name for each new task. |
| **Starts chats** | New chats start on it. Each chat can switch. |

Until you pick one, **Makes quick choices** and **Starts chats** use the model that names tasks. A chat needs a model that calls tools: in the **Starts chats** menu, one that doesn't is dimmed and says "No tool calls".

The **Makes quick choices** menu lists decision models first. Under **Or a language model**, you can pick any language model instead, and the row marks it "Language model". A different model there from the one that names tasks costs one more small request for each new task's name.

When a model has effort levels, a chip beside it picks one. `default` sends no effort, so the provider's own default applies.

## Decision *models*

A decision model answers with a choice instead of text, so it places tabs faster and for less than a language model. The **Makes quick choices** menu lists them first, and the other menus leave them out. The provider list counts them, as in "51 models · 1 decision".

| Provider | Its decision models |
| --- | --- |
| **Vercel AI Gateway** | The ones its own list marks, such as `openai/gpt-6-luna-decisions` and `typesafe-ai/jev` |
| **OpenRouter** | The ones in its list of decision models, such as `liquid/d1` |
| **OpenAI** | The ones that answer when uw asks, such as `gpt-6-luna` |
| **Jev** | All of them |
| **Custom**, in a decision format | The ones that answer when uw asks |

OpenAI's list doesn't say which models make decisions, so uw sends each model one small request the first time it lists them, and says "checking" meanwhile. Each costs a tiny fraction of a cent, and a model that turns it down costs nothing. uw asks a model that turned it down again a week later, and asks again when you change the provider's key.

**Test** beside **Makes quick choices** or **Names tasks** sends that model one small request. It says how long the model took to answer, or why it failed. **Details** shows what uw sent and what came back.

## Use *another address*

Every provider's address can change. The **Add provider** dialog shows a preset's address ready to edit, and **Change** on a provider's page takes a new one. uw saves a new address only once it can list the models there. Otherwise it says why and keeps the old one.

An address is https, or plain http on this Mac or your own network, such as `http://192.168.1.20:8317/v1`.

<Callout>
  For a proxy such as CLIProxyAPI, add a **Custom** provider at `http://localhost:8317/v1` with the format **Each model's own**. Claude models then go over Anthropic's format, GPT models over OpenAI's, and the rest over chat completions.
</Callout>
