---
title: Install uw
description: Download uw for your Mac, or install it with Homebrew. uw needs a Mac with Apple silicon and macOS 13 or later.
---

## Download *the app*

1. Go to [uwbrowser.com](https://uwbrowser.com) and click **Download for Mac**.
2. Open the downloaded file and drag uw to your Applications folder.
3. Open uw from Applications.

uw is signed and notarized by Apple, so it opens like any other app. It doesn't run on Intel Macs.

## Or install it *with Homebrew*

```bash title="Terminal"
brew install --cask leetdavid/uw/uw
```

This installs the latest release, the same one the website offers. It doesn't add the `uw` command. For that, see [Install the command](./install-the-command.mdx).

## The first time *you open it*

- A card at the foot of the sidebar asks **Help fix uw?** Choose **Send reports** or **Don't send**. Nothing is sent unless you say yes. See [Report a problem](./report-a-problem.mdx).
- Automatic organization and chats need an AI provider of your own. Start with [Add an AI provider](./add-an-ai-provider.mdx).

<Callout>
  uw is an early preview. It may break, and it comes with no support promise. If something goes wrong, [report it](./report-a-problem.mdx).
</Callout>
